# Распаковщик

Небольшая программа для Windows, которая распаковывает архивы **ZIP, RAR и 7z** и умеет работать с **.torrent**-файлами. Окно простое, в стиле Rufus: выбрал файл, выбрал папку, нажал СТАРТ.

Программа написана на C++ (чистый Win32 API), состоит из одного файла и собирается в один `.exe`. Устанавливать её не нужно.

## Зачем она нужна

Фильмы и большие файлы часто лежат в архивах, а иногда ещё и в торрентах. Эта программа убирает лишние шаги:

- не нужно открывать несколько программ для разных форматов;
- перед распаковкой видно, хватит ли места на диске;
- прогресс показан наглядно, процесс можно остановить в любой момент;
- в окне нет лишних настроек, только то, что нужно.

## Возможности

### Форматы
- **ZIP, RAR, 7z** и другие архивы (tar, gz, iso, многотомные `.part1.rar` и `.001`).
- **.torrent**: скачивание файлов с последующей автоматической распаковкой архивов внутри (нужна сборка с libtorrent, см. ниже).

### Выбор файла и папки
- Кнопка **ВЫБРАТЬ** открывает обычный диалог выбора файла.
- Файл можно **перетащить мышкой** прямо в окно.
- Папку назначения можно **выбрать кнопкой ОБЗОР** или **вписать путь вручную**.
- Если указанной папки нет, программа **создаст её сама**, включая вложенные (например, `D:\Фильмы\2026\Новый`).
- По умолчанию предлагается папка «Видео».

### Проверка места на диске
- Блок «Место на диске» показывает, сколько **свободно** на выбранном диске и сколько **нужно** для распаковки.
- Размер считается сразу после выбора архива и обновляется при смене папки.
- Если места не хватает, надпись становится **красной**: «НЕ ХВАТАЕТ МЕСТА!».
- Перед стартом проверка повторяется. Если места мало, распаковка не начнётся, а вы увидите, сколько нужно и сколько свободно.
- Если диск указан неверно, программа об этом предупредит.

### Процесс распаковки
- **Прогресс-бар** с процентами и строка состояния.
- Кнопка **СТОП** прерывает работу в любой момент.
- Распаковка идёт в фоне, окно не зависает.
- При закрытии во время работы программа спросит подтверждение.

### Параметры
- **Распаковать архивы после загрузки торрента**: после скачивания торрента программа сама найдёт архивы внутри и распакует их.
- **Удалить архив после распаковки**: освобождает место после успешной распаковки.

### Сообщения об ошибках
Если что-то пошло не так, программа объясняет причину: не найден 7-Zip, архив повреждён или защищён паролем, нет остальных частей, закончилось место, неверный путь.

## Что нужно для работы

| Что | Зачем | Где взять |
|---|---|---|
| **7-Zip** | распаковка ZIP, RAR, 7z | https://www.7-zip.org/ |
| **libtorrent** (только при сборке) | поддержка .torrent | `vcpkg install libtorrent` |

7-Zip достаточно просто установить, программа найдёт его сама.

## Как пользоваться

1. Запустите `unpacker.exe`.
2. Выберите архив или `.torrent` (кнопкой или перетащив в окно).
3. Укажите папку назначения.
4. Проверьте блок «Место на диске». Он должен показывать, что места хватает.
5. Нажмите **СТАРТ**.
6. Дождитесь сообщения «Готово».

Если фильм разбит на части (`.part1.rar`, `.part2.rar` и так далее), выбирайте **первую** часть. Остальные 7-Zip подхватит сам.

## Сборка

**Автоматически (GitHub Actions).** Положите файлы в репозиторий так, как они лежат в архиве проекта, и сделайте push. Во вкладке Actions появится готовый `unpacker.exe`. Если запушить тег вида `v1.0`, `.exe` прикрепится к релизу.

**Вручную, MSVC** (Developer Command Prompt):

```
rc /nologo resource.rc
cl /EHsc /O2 /MT /DUNICODE /D_UNICODE unpacker.cpp resource.res /link /SUBSYSTEM:WINDOWS
```

**Вручную, MinGW-w64:**

```
windres resource.rc -O coff -o resource.o
g++ -O2 -municode -mwindows unpacker.cpp resource.o -o unpacker.exe -lcomctl32 -lcomdlg32 -lshell32 -lole32
```

**Поддержка торрентов.** Добавьте при сборке флаг `/DUSE_LIBTORRENT` и подключите libtorrent. Без него программа работает как распаковщик архивов, а при выборе `.torrent` подскажет, что делать.

## Ограничения

- Только Windows.
- Для архивов с зашифрованным списком файлов размер может быть неизвестен. Тогда проверка места пропускается, но распаковка идёт.
- Для торрента проверка места учитывает только размер загрузки, без учёта распаковки архивов внутри. Для них понадобится больше места.
- Архивы с паролем не поддерживаются.
